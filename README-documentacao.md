# Documentação de Apoio

Este pacote contém documentos de apoio para organizar e desenvolver o teste técnico de Anotação de Dados + Angular.

## Arquivos

- `docs/criterios-de-anotacao.md`: regras das quatro classes, bounding boxes, ambiguidades e revisão humana.
- `docs/decisoes-tecnicas.md`: registro de decisões arquiteturais e técnicas.
- `docs/estrutura-e-entregaveis.md`: estrutura sugerida, entregáveis, componentes, serviços e rastreabilidade.
- `docs/checklist-dataset.md`: checklist operacional de coleta, anotação e validação.
- `dataset/README.md`: documentação local do dataset.
- `dataset/sources/image_sources.csv`: planilha-modelo para registrar a origem das imagens.

## Como utilizar

1. Copie os diretórios `docs/` e `dataset/` para o repositório do projeto.
2. Mantenha o `guia-de-desenvolvimento.md` como documento principal de instruções do agente.
3. Preencha o CSV à medida que coletar as imagens.
4. Revise e aprove os critérios de anotação antes de iniciar a anotação em massa.
5. Atualize o registro de decisões sempre que uma escolha técnica relevante for feita.
6. Não marque itens como concluídos sem evidências.

## Observação

Os documentos distinguem requisitos explícitos do teste de recomendações organizacionais e decisões propostas. Em caso de divergência, o documento original do teste técnico prevalece.
